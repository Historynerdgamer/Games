# America Builder

A playable browser prototype of a top-down town-building game.

## Run locally

Open `index.html` directly in a browser, or serve the folder with:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Features

- Top-down 2D city grid
- Infinite money
- Place roads, homes, skyscrapers, parks, and landmarks
- Visible buildings remain on the map when placed
- Explore a city for all 50 US states
- Dynamic state-specific city flavor and famous landmarks
